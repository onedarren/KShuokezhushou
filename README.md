# 快手AI自动获客助手（开源版）

原 Chrome 扩展「快手自动评论助手 v1.0.2」的**用户脚本（UserScript）移植版**，移植方式 1:1 参考同系列的「抖音AI自动获客助手（开源版）」项目。

- ✅ **免费开源，无需授权** —— 原版的授权码校验、机器码（SHA-256）绑定、`api.devstorex.top` 授权服务器调用已全部移除
- ✅ 支持 **油猴（Tampermonkey）** 和 **脚本猫（ScriptCat）**
- ✅ 功能与原版 100% 一致：关键词搜索任务模式，点赞、收藏、评论（文本随机 / AI 回复），关键词自动轮换与进度恢复（逐条对比见 [docs/功能对比报告.md](docs/功能对比报告.md)）

> ⚠️ **免责声明**：本项目仅供学习交流，请勿用于任何违反快手平台规则或法律法规的用途。使用本脚本产生的一切后果由使用者自行承担。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [ScriptCat](https://scriptcat.org/) 扩展
2. 新建脚本，粘贴 `userscript/dist/快手AI自动获客助手.user.js` 的全部内容并保存
   （或在脚本猫中导入该文件）
3. 打开 [https://www.kuaishou.com](https://www.kuaishou.com)，页面右侧会出现「🎤 快手AI自动获客助手」浮动面板

## 功能说明

| 功能 | 说明 |
| --- | --- |
| 关键词模式 | 按关键词打开快手搜索页（`/search/video?searchKey=`），逐视频执行操作，支持中英文逗号/顿号分隔多个关键词 |
| 搜索筛选 | 排序依据 / 发布时间 / 视频时长 / 搜索范围（与抖音版一致的面板选项，自动在筛选面板中点选） |
| 操作类型 | 点赞、收藏、评论可任意组合 |
| 评论方式 | 回复评论（自动定位「回复」按钮）/ 直接评论 |
| 评论类型 | 表情（表情面板随机 / 文本表情兜底）/ 文本（多行随机）/ AI（DeepSeek、Kimi、OpenAI、OpenRouter、Gemini、小米 MiMo、Ollama） |
| 回复过滤 | 包含关键词（仅回复含这些词的评论）/ 排除关键词（跳过含这些词的评论）；回复前点赞；仅一级评论 |
| 评论数量 | 每视频评论数 / 每关键词视频数 / 评论间隔（秒）可自由配置 |
| 快捷键兜底 | 找不到按钮时模拟快手快捷键：Z 点赞、C 收藏、X 评论区、K 关连播 |
| 视频切换 | 「下一个视频」按钮优先；指纹校验失败自动转方向键（ArrowDown）兜底并重试 3 次；仍失败则重开搜索页续跑 |
| 连播检测 | 自动检测并关闭「连播/自动播放」，保证逐视频操作 |
| 禁评检测 | 「仅作者及作者好友可评论」等禁评视频自动跳过 |
| AI 评论 | 抓取视频描述 + 用户评论生成回复；AI 失败自动回退文本评论 |
| 参数校验 | 与抖音版一致的校验规则与提示文案 |
| 进度与恢复 | 任务进度（关键词序号/视频序号/评论数）持久化存储，页面跳转后自动续跑；卡住 5 分钟自动恢复 |
| 完成统计 | 任务完成后弹窗 + 系统通知：关键词 / 视频 / 成功评论总数 |

## 使用流程

1. 在面板中填写搜索关键词，勾选操作类型（点赞/收藏/评论），配置评论类型与内容
2. 点击「开始任务」，脚本自动打开搜索页并点开第一个视频逐个执行
3. 面板下方实时显示关键词/视频/评论进度；「停止任务」可随时中断
4. 任务运行中刷新页面或跳转后，回到搜索页会自动续跑

## AI 评论配置

选择评论类型为「AI评论」，填写对应平台的 API Key（Ollama 为本地模型，无需 Key，可自定义接口地址与模型名）。
AI 请求通过 `GM_xmlhttpRequest` 直连各平台接口，无需担心跨域问题（对应原扩展的 `host_permissions` 声明）。

## 构建

```bash
cd userscript/src
node build.js
```

## 与原扩展的差异

| 差异点 | 原扩展 | 开源版 |
| --- | --- | --- |
| 授权 | 授权码 + 机器码绑定 + 远程校验 | 无，全部功能免费可用 |
| 运行形态 | Chrome 扩展（background + content + popup） | 油猴用户脚本（页面内浮动面板替代 popup） |
| 跨域 AI 请求 | `fetch` + `host_permissions` | `GM_xmlhttpRequest` + `@connect` |
| 任务调度 | background service worker 通过 tabs API 导航 | 页面内通过 `location.href` 导航 + 存储续跑 |
| 完成提醒 | `alert`（注入页面执行） | `alert` + `GM_notification` 系统通知 |
